# DM Table Forge

`Duelmasters.db` をカードライブラリとして使う、手動操作型のWeb対戦テーブルMVPです。ゲームルールを自動処理するのではなく、実際のカードゲームのようにプレイヤーがカードを動かすことを中心にしています。

## 起動

Python 3.8 以上で、プロジェクトルートから起動します。

```powershell
python .\duel_simulator\server.py
```

ブラウザで <http://127.0.0.1:8765> を開いてください。

`server.py` はLAN接続もできるよう `0.0.0.0` で待ち受けます。現段階では認証・ルームパスワードが未実装なので、インターネットへポート公開せず、同じPCまたは信頼できるLAN内だけで使用してください。

DBと画像の場所は [server.py](C:/Users/EtoHayato/Desktop/projectDM/duel_simulator/server.py) 上部の `DATABASE_DIRECTORY`、`DATABASE_FILENAME`、`IMAGE_DIRECTORIES` を変更します。DBの `imagefile` 列に記載されたファイルが画像ディレクトリ内に存在すれば、その画像を表示します。

## 現在の操作

- カードをクリック：選択。`Ctrl` / `Command` を押しながら複数選択
- 右クリック：選択カードの操作メニュー
- カードをドラッグして別のカードへドロップ：同じゾーン内で位置交換
- カードをドラッグしてゾーンへドロップ：ゾーン移動
- カード上でホイール上回転：タップ、下回転：アンタップ
- カードにマウスを乗せる：カード画像と能力テキストを拡大表示
- フィールド上ではカード名を表示せず、カード画像を中心に表示
- 裏向きカード：横の影を付けず、設定でダミー表示／シンプル柄を切り替え
- カード配置：マナ以外は各ゾーンの中央寄せ、マナは右寄せ。カーソルを合わせたカードは画面左の専用スペースで拡大表示
- バトルゾーン：自分側・相手側ともにゾーン高さの約90%を基準に画像を表示
- 山札の「ドロー」：山札の一番上を手札へ移動
- 山札の「見る」：山札上部を確認し、選んだカードを各ゾーンへ移動
- 山札：カード内容を見せない裏向きのスタック表示。「見る」から必要なときだけ確認
- シールド：裏向きのカードを束ねず、横並びで表示
- 自分側の手札：シールドとマナゾーンの間に配置
- 墓地・超次元・ガチャレンジ・深淵：ゾーンまたは表示カードをクリックすると含まれるカードを展開表示し、別のフィールドをクリックすると1枚表示へ戻る
- マナゾーン：通常は文明色の球で表示。クリックでカード画像を展開し、球の上でホイール上回転／下回転すると使用済み（灰色）／未使用へ切り替え
- マナゾーン：多色カードは2色なら斜め2分割、3～5色なら等分割で表示。ツインパクトは上下両面の文明を合算
- マナゾーンの簡易表示：文明を色分けした球を見やすい大きさで表示
- 相手側：バトルゾーンを大きく、その他のゾーンを小さく表示
- 相手側の配置：自分側を上下反転し、マナ・手札・シールド／山札／墓地・バトルゾーンの順に配置
- カード表示：各ゾーンの内寸と枚数からカード画像を自動調整し、通常表示ではスクロールバーを出さず、必要に応じて2段へ折り返す
- 自分側：バトルゾーンの下にシールド・山札・墓地、その下にマナゾーンを配置。特殊ゾーンは墓地の上側に配置
- 特殊ゾーン：デッキに該当カードがない場合は開始時に自動非表示。カードが送られると自動表示
- 左クリック長押しでフィールド上をドラッグ：範囲内のカードを複数選択
- 「表示設定」：カードサイズ、自分／相手それぞれのバトルゾーンと補助ゾーンの配分比率、ゾーン名の位置、裏面ダミー表示を変更（ブラウザに保存）
- 「表示設定」：カード縦比率を60〜100%で変更（初期値100%、ブラウザに保存）
- 「リモートモード」：自分のフィールドだけを本体画面に表示し、手札を別ウィンドウに分離。Discordでは本体画面だけを共有
- 「ゾーン表示」：超次元・ガチャレンジ・深淵を表示/非表示
- 「全画面」：ブラウザのFullscreen APIでフィールドを拡大
- デッキ作成画面の「保存」：カードIDをJSONファイルとして保存
- デッキ作成画面の「読み込み」：保存したJSONを読み込み、DBからカード情報を復元

右クリックメニューから、手札・マナ・墓地・バトルゾーン・超次元・ガチャレンジ・深淵への移動、山札の上/下への移動、山札へ戻してシャッフル、山札から裏向きのままマナへ移動、表裏、タップ/アンタップを実行できます。

## 画像

DBの `imagefile` 列に入っているファイル名を使い、次のフォルダを順に探します。

- `card_images/`
- `dm_data/`

画像ファイルが未配置の場合は、画面側のダミーアートを表示します。`dm_data.zip` は必要に応じて `dm_data` フォルダへ展開してください。

## オンライン化

現在は同じサーバー上の1つのテーブルを操作するMVPです。対戦状態はサーバー側にあり、操作は `/api/tables/{table_id}/commands` に集約されています。状態は1秒ごとに再取得するため、同一LAN上の複数ブラウザでの試験へ拡張できます。次の段階では、プレイヤー認証、ルームパスワード、プレイヤーごとの操作権限、WebSocketによる状態配信を追加します。これにより、Minecraftのように管理者がサーバーを起動し、接続先を知っている参加者だけが入る構成へ拡張できます。

カード画像の利用・配布は、権利者のサイトポリシーや利用許諾を確認した範囲で行ってください。
