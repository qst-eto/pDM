# DM Table Forge

`Duelmasters.db` をカードライブラリとして使う、手動操作型のWeb対戦テーブルMVPです。ゲームルールを自動処理するのではなく、実際のカードゲームのようにプレイヤーがカードを動かすことを中心にしています。

## 起動

Python 3.8 以上で、`pDM` フォルダ内から起動します。

```powershell
python .\server.py
```

ブラウザで <http://127.0.0.1:8765> を開いてください。

`server.py` はLAN接続もできるよう `0.0.0.0` で待ち受けます。通信対戦ではプレイヤーごとの接続情報で盤面を保護しますが、ルームパスワードや通信の暗号化はありません。インターネットへ直接ポート公開せず、同じPCまたは信頼できるLAN内で使用してください。

DBと画像の場所は [server.py](server.py) 上部の `DATABASE_DIRECTORY`、`DATABASE_FILENAME`、`IMAGE_DIRECTORIES` を変更します。既定では `server.py` と同じフォルダの `Duelmasters.db` と `dm_data/` を参照するため、フォルダ名や起動時の作業ディレクトリが変わっても動作します。DBの `imagefile` 列に記載されたファイルが画像ディレクトリ内に存在すれば、その画像を表示します。

## 現在の操作

- カードをクリック：選択。`Ctrl` / `Command` を押しながら複数選択
- 右クリック：選択カードの操作メニュー
- 右クリックの「特殊ゾーンへ」をクリック：超次元・ガチャレンジ・深淵への移動を選択。本体とリモート手札ウィンドウの両方に対応
- カードをドラッグして別のカードへドロップ：ドラッグしたカードを対象カードの一番上へ重ねる
- カードをドラッグしてゾーンへドロップ：ゾーン移動。重なったカードは通常ドラッグで一番上の1枚、`Ctrl` / `Command` を押しながらドラッグすると重なり全体を移動
- ドラッグ中のホイール：ドラッグしているカードの表向き／裏向きを切り替え
- カード上でホイール上回転：タップ、下回転：アンタップ
- カードにマウスを乗せる：カード画像と能力テキストを拡大表示
- フィールド上ではカード名を表示せず、カード画像を中心に表示
- 裏向きカード：横の影を付けず、設定でダミー表示／シンプル柄を切り替え
- カード配置：マナ以外は各ゾーンの中央寄せ、マナは右寄せ。カーソルを合わせたカードは画面左の専用スペースで拡大表示
- 対戦画面：中央の操作説明欄を省き、相手側と自分側でフィールドの上下を使用
- カード画像：650×909の縦横比を維持し、初期設定ではゾーン内側のほぼ全高まで表示。タップ時の横長の占有範囲も考慮して配置
- 山札の「ドロー」：山札の一番上を手札へ移動
- 山札の「見る」：山札上部を確認し、選んだカードを各ゾーンへ移動
- 山札・墓地などの詳細一覧：左のカード確認欄を空けて右側に表示。一覧のカードにカーソルを合わせるかキーボードでフォーカスすると、通常と同じ左欄に画像と能力を表示。右クリックでは通常画面と同じカード操作を実行可能。裏向きのカードは詳細を表示しない。Escapeでも一覧を閉じられる
- 山札：カード内容を見せない裏向きのスタック表示。「見る」から必要なときだけ確認
- シールド：裏向きのカードを束ねず、横並びで表示
- 自分側の手札：シールドとマナゾーンの間に配置
- 墓地・超次元・ガチャレンジ・深淵：ゾーンまたは表示カードを左クリックすると、山札と同じ一覧UIで含まれるカードを確認できる
- 重なったカード：右クリックの「カードを重ねる」から表裏・対象カード・上下を指定して重ねられ、重なりを左クリックすると内容を確認できる。向きが違う下側のカードは実際のカード画像全体を下に描画して横から一部を見せ、その部分へカーソルを合わせると下カード、上側へ合わせると最上面カードを左欄で確認できる。メモは一番上のカードに付く
- マナゾーン：通常は文明色の球で表示。クリックでカード画像を展開し、球の上でホイール上回転／下回転すると使用済み（灰色）／未使用へ切り替え
- マナゾーン：多色カードは2色なら斜め2分割、3～5色なら等分割で表示。ツインパクトは上下両面の文明を合算
- マナゾーンの簡易表示：文明を色分けした球を見やすい大きさで表示
- 相手側：バトルゾーンを大きく、その他のゾーンを小さく表示
- 相手側の配置：自分側を上下反転し、マナ・手札・シールド／山札／墓地・バトルゾーンの順に配置
- カード表示：各ゾーンの内寸と枚数からカード画像を自動調整し、通常表示ではスクロールバーを出さず、必要に応じて2段へ折り返す
- 自分側：バトルゾーンの下にシールド・山札・墓地、その下にマナゾーンを配置。特殊ゾーンは墓地の上側に配置
- 特殊ゾーン：デッキに該当カードがない場合は開始時に自動非表示。カードが送られると自動表示
- 左クリック長押しでフィールド上をドラッグ：範囲内のカードを複数選択
- 「表示設定」：カードサイズ、自分／相手それぞれのバトル、待機・シールド・山札・墓地のセット、手札、マナの高さ配分、ゾーン名の位置、裏面ダミー表示を変更（ブラウザに保存）。高さ設定ではゾーンの横幅は変わらない
- 「表示設定」：カード縦比率を60〜100%で変更（初期値100%、ブラウザに保存）
- 「表示設定」：自分フィールド全体の高さ配分を10〜190%で変更。100%で上下半分、190%で自分95%／相手5%。相手側のスライダーも連動する（ブラウザに保存）
- フィールドのゾーン間は余白をなくして1pxの境界線で表示。カードは画像の縦横比を維持して、境界の直前までの高さを使う。枚数・横幅に収まらない場合は縮小または折り返す
- 旧版の補助ゾーンの配分は各段へ分解して引き継ぐ。リモートモードでは別ウィンドウの手札を除いて高さを配分する
- 旧版のバトルカード横幅設定は画像本来の縦横比に統一。カード縦比率とゾーン配分の保存値は引き継ぐ
- 「リモートモード」：自分のフィールドだけを本体画面に表示し、手札を別ウィンドウに分離。Discordでは本体画面だけを共有
- 「通信対戦の部屋を作る」：6桁の部屋番号を発行し、相手が参加するまでは相手側を空の状態で表示
- 「部屋番号で通信対戦に参加」：ホストと同じIPアドレス・ポートをブラウザで開き、プレイヤー名と6桁の部屋番号を入力。参加者自身のデッキから山札、手札、シールド、超次元、ガチャレンジ、開始時バトルゾーンを作成
- 通信対戦中は双方の画面で自分を手前、相手を奥に表示。手札と「山札を見る」の内容は持ち主にだけ表示し、裏向きシールド・裏向きGRなどはどちらにも内容を見せない。カードの移動・表裏・タップ・重なり・超次元の面変更は公開状態に従って1秒以内に相手側へ反映
- 通信対戦では相手のカード、山札、詳細一覧を操作不可。ブラウザから不正な操作を送った場合もサーバー側で拒否
- 3人目以降は観戦者として同じ部屋へ参加。観戦者は両プレイヤーの公開盤面を確認できるが、カード操作、詳細一覧からの移動、ターン終了は不可
- 自分の手札にある「対戦相手に公開／非公開」で、対戦相手へ手札全体を公開または非公開に変更
- 手札カードの右クリックにある「相手に見せる」で、選択中のカードだけを対戦相手へ公開。「相手に見せるのをやめる」で再び非公開にでき、観戦者向けの公開状態には影響しない。カードを手札から移動すると個別公開は解除
- 「観戦者に公開／非公開」は観戦者だけへの手札公開設定。対戦相手向けの公開設定とは独立しているため、観戦者にだけ公開することも可能
- 表示設定は各ブラウザに保存されるため、フィールドの高さ配分や各ゾーンの大きさを変えても相手の表示には影響しない
- 「ターン終了」：手番を相手へ渡し、両方の画面の手番表示を更新。通信対戦では現在の手番プレイヤーだけが実行可能
- 通信対戦の開始時はサーバー側のコイントスで先攻を決定。「対戦をやり直す」で両者の登録デッキを再シャッフルし、シールド・初期手札・特殊ゾーンを開始状態へ戻して先攻も決め直す
- 通信対戦の接続情報は同じタブのセッションに保存されるため、再読み込み後も同じプレイヤーとして部屋へ復帰可能。「デッキへ戻る」で接続情報を消去
- ゲーム開始時：自分と相手の山札をシステム乱数でシャッフルしてから、シールドと初期手札を配布
- 「ゾーン表示」：超次元・ガチャレンジ・深淵を表示/非表示
- 「全画面」：ブラウザのFullscreen APIでフィールドを拡大
- デッキ作成画面の「サーバーに保存」：サーバー配下の `saved_decks/` にデッキJSONを自動生成
- デッキ作成画面の「今までのデッキ」：ブラウザ起動時にサーバー保存済みデッキを一覧表示し、クリックで復元
- デッキ内リスト：カード画像で表示し、同じカードを `×4` のようにまとめる。`−` / `＋` で1枚ずつ変更し、DBに画像が複数あるカードは使う画像を選択して保存できる
- デッキ作成の「カードの追加先」：通常の山札、ガチャレンジ、超次元、開始時バトルゾーンを個別に編集。追加先に合わせてライブラリのカード種別を絞り込み、4枠をまとめて保存・復元
- ガチャレンジ：使用する場合は基本12枚。山札に混ぜず、開始時にシャッフルして全カードを裏向きでガチャレンジゾーンへ配置。一番上も非公開。バトルへ移動するとカードの内容を表示
- 超次元：基本8枚以下。山札に混ぜず、登録した順序と面で超次元ゾーンへ配置。両面は1枚として扱うため、作成時は開始時に表示する面を1つ選択
- 開始時バトルゾーン：登録したカードを、山札とは別に開始時からバトルゾーンに配置。特殊カードをここへ登録した場合も、GR・超次元の合計枚数に含める
- 枚数が揃う前でもデッキを保存可能。GRが12枚以外、超次元が8枚を超える場合は開始不可。変則対戦では「特殊デッキの枚数制限を外す」を指定できる
- 超次元カードの右クリック：同じ `packname` の別面へ変更。3段階覚醒（同じpacknameが3枚以上）は「コストが大きい方へ裏返す」「コストが小さい方へ裏返す」で、コスト順の隣の段へ変更。サイキックリンクなど同じコストの複数候補は候補名を選択。カード名に `/` または `／` を含むツインパクトは対象外。カードの位置・タップ・重なりは維持
- GR・超次元カードの移動先：元の特殊ゾーン、バトル、深淵のみ。右クリックと詳細一覧で禁止先を無効にし、ドラッグや重なったカードの移動もサーバー側で検証
- 待機ゾーン：両プレイヤーのシールド左側に配置。通常は最後の1枚だけを表示し、左クリックで含まれるカードの一覧を確認。右クリック、ドラッグ、山札などの詳細一覧、別画面手札から移動可能
- 「相手に非公開で待機ゾーンへ」：持ち主にはカード内容と非公開表示を見せ、対戦相手と観戦者には裏向きカードとして同期
- カードの右クリックにある「メモをつける／編集する」：120文字までの共有メモを保存。メモはカード右上の付箋として表示され、カードが公開されている相手と観戦者にも同期。非公開カードのメモは持ち主以外へ送られず、空欄で保存すると削除
- 旧形式の保存デッキも読み込み可能。通常デッキ内のGR・超次元カードは、それぞれの特殊枠へ移す

右クリックメニューから、手札・マナ・墓地・待機・バトルゾーン・シールドゾーン・超次元・ガチャレンジ・深淵への移動、山札の上/下への移動、山札へ戻してシャッフル、裏向きのままマナへ移動、相手に非公開で待機ゾーンへ移動、表裏、タップ/アンタップ、メモの追加・編集を実行できます。複数選択中は選択された全カードへ同じ操作を適用します。シールドゾーンへ移動する際は、裏向きまたは表向きを選べます。カード画像上にコスト数の追加表示は行いません。

## 画像

DBの `imagefile` 列に入っているファイル名を使い、次のフォルダを探します。

- `dm_data/`

画像ファイルが未配置の場合は、画面側のダミーアートを表示します。`dm_data.zip` は必要に応じて `dm_data` フォルダへ展開してください。

## 通信対戦

ホストPCでサーバーを起動し、ホストは開始画面で「通信対戦の部屋を作る」を選びます。表示された6桁の部屋番号を相手へ伝えてください。相手はブラウザで `http://<ホストPCのIPアドレス>:8765` を開き、「部屋番号で通信対戦に参加」を選んで同じ番号を入力します。

対戦状態はホストPCのメモリ上に保存され、1秒ごとに各端末へ同期します。サーバーを終了すると作成中の部屋も消えます。最初の2人がプレイヤーとなり、3人目以降は観戦者として参加します。

カード画像の利用・配布は、権利者のサイトポリシーや利用許諾を確認した範囲で行ってください。
