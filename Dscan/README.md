# pDMで使用するDscan

以前作成した `dm_deck_recognizer` 初期版から、学習不要の画像認識モジュールを同梱しています。独立版の `Dscan/dm_deck_recognizer.zip` はそのまま残しています。

- `deck_recognizer/`：元のDscanの領域検出、特徴抽出、索引、照合を変更せず使用。
- `requirements.txt`：Dscanの依存関係。ルートのrequirements.txtから参照。
- `cache/`：pDMから実行したときの索引。自動生成、Git対象外。

pDMとの連携はルートの `deck_image_import.py` が担当します。索引中のファイルパスを、**pDM自身のDB**の `image_files` と対応付けて `id` と `image_index` を返します。Dscanのカード名やカードIDをpDMのIDとして流用しません。pDMが表示できない画像は認識候補から除外します。

元の画像・カードDBへ書き込みません。アップロードされた画像は解析中の一時ファイルを削除し、切り出しプレビューはレスポンス内に返します。ユーザーが通常の保存ボタンを押すまでは、デッキJSONを保存しません。

認識は全体／絵柄のpHashと色特徴で候補を検索し、SSIMで再ランキングします。初期閾値はスコア0.76、候補差0.025。候補をpDMのカードID単位にまとめ直し、同じカードの複数画像は画像番号を保って選択肢に含めます。画像の違いを含む保留判定と、一致度不足の領域を画面で確認できます。
